# Персонализация кешбэк-предложений на основе машинного обучения
Учебный проект, демонстрирующий полный цикл разработки ML-системы для прогнозирования потребительских предпочтений клиентов банка и формирования персонализированных кешбэк-предложений.

Задача: Разработать модель, которая по истории транзакций и профилю клиента предсказывает топ-5 категорий трат на следующий месяц, и на основе этих предсказаний сформировать персонализированные кешбэк-предложения с дифференцированными ставками по сегментам клиентов.

## Что сделано:
Сгенерированы синтетические данные с помощью Faker: 15 000 клиентов с профилями (возраст, доход, кредитный рейтинг, город, сегмент) и 531 339 транзакций за период сентябрь 2025 – апрель 2026.

Проведён разведочный анализ данных (EDA): распределение по сегментам, топ категорий по количеству клиентов, сезонные изменения, структура расходов.

Сформирована целевая переменная – топ-5 категорий трат на май 2026 на основе апрельских транзакций (для активных клиентов) или мартовских (для неактивных).

Разработаны 126 признаков: агрегаты по суммам и количествам транзакций в разрезе 30 категорий, доли категорий, временные паттерны (ночные/выходные транзакции), профиль клиента, производные признаки (отношение трат к доходу и т.п.).

Обучены две модели MultiOutput классификации: LightGBM и CatBoost. Лучший результат показал CatBoost с F1-samples = 0.7420.

Проведён детальный анализ качества: по категориям (лучшие – Продукты, Рестораны, Транспорт), по сегментам клиентов (лучший – inactive, F1 = 0.8695), анализ важности признаков.

Разработан прототип системы персонализации кешбэка (CashbackRecommendationSystem), который автоматически назначает ставки кешбэка в зависимости от сегмента клиента и предсказанных категорий.

Сформулированы бизнес-преимущества, KPI, план поэтапного внедрения и перспективы развития.

# Стек технологий
Python 3.10+, pandas, numpy, scikit-learn, LightGBM, CatBoost, matplotlib, seaborn, Faker, joblib. Среда разработки — Jupyter Notebook / Google Colab.

# Ключевые результаты
Разработанная модель достигает F1-score (samples) = 0.7420 на тестовой выборке, что несколько ниже целевого значения 0.85, но демонстрирует высокое качество для наиболее популярных категорий: Продукты (F1 = 0.97), Рестораны (0.93), Транспорт (0.86). Наиболее важными признаками оказались доля и абсолютные траты на АЗС, а также паттерны времени совершения покупок (ночные и выходные транзакции).

Система персонализации использует матрицу кешбэк-ставок, дифференцированную по 6 сегментам: от 10% для приоритетных категорий премиум-активных клиентов до 1.5–3% для активных и обычных клиентов. Это позволяет целенаправленно стимулировать траты в предсказанных категориях и оптимизировать бюджет программы лояльности.

Предложен план внедрения, включающий пилотный проект, A/B-тестирование, масштабирование и постоянное дообучение модели. В перспективе – добавление сезонных факторов, real-time рекомендаций, интеграция с геолокацией и партнёрскими программами.
