В Файле Вкр_Код содержится итоговая версия работы, в которой создается модель для персонализации кешбэк предложений. В вкр доп анализ содержится более расширенная версия работы с большим числом визуализации и со сравнением 4х моделей вместо 2х.
Далее скачиваются файлы модели, на основе которых строится веб сервис. После запуска кода по порядку, после раздела 2.3, загружаются файлы, необходимые поместить в одну папку вместе с App.py для последующего запуска веб сервиса через командную строку.
Файл App.py находится в папке VCR, туда необходимо поместить артефакты модели и далее через командную строку перейти в папку, и запустить через python app.py
