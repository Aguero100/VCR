Запуск веб-сервиса: 
Выполните ноутбук ВКР_Код (или ВКР доп анализ) последовательно до раздела 2.3 включительно. 
В процессе выполнения будут созданы и скачаны следующие файлы:

best_model.pkl,
mlb.pkl,
categories.pkl,
model_columns.pkl,
df_features.csv,
df_customers.csv

Поместите все эти файлы в папку VCR рядом с файлом App.py.

Откройте командную строку (терминал), перейдите в папку VCR:

bash
cd путь/к/папке/VCR

Запустите веб-сервис:

bash
python app.py.

После запуска сервер будет доступен по адресу, указанному в консоли (обычно http://127.0.0.1:5000).
